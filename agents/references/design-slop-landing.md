# Design Slop — Landing, Hero and Brand-Mark Rows

> Extension of the trope SoT: `~/.claude/agents/glass-atrium-design-designer.md` → `### AI Slop Tropes (forbidden patterns — Single SoT for all DEV agents)`.
> "SoT" and the bold leads below name entries in that file.

## Scope and precedence

- **Covers**: landing pages, heroes, marketing sections and brand marks.
  - Product UI and admin consoles use the SoT's own bundles.
- **Precedence**: a brand spec or the selected direction's posture outranks every row — a pattern either one names is not the trope.
- **Missing asset**: a hero visual, screenshot or logo the user has not supplied stays a labeled placeholder (**Placeholder First**).
- **No invented content**: a replacement never invents a product preview, metric, customer name or quote (SoT → **Content tropes**).
- **Rows are decisions and tests, not layouts**: each row names what to decide; the selected posture supplies the form.

## Copy and actions

Applies to heroes and marketing sections.

| Trope | Decide instead | Passes when |
|---|---|---|
| A launch or feature announcement in a rounded chip over the headline | drop it; a genuine announcement gets one plain inline link | the news is supplied by the user and dated |
| Headline copy that holds equally for a product from an unrelated category | name the job this product performs, and the user it serves, in the product's own vocabulary | the line is false when read as describing a product from an unrelated category |
| A cluster of buttons, tags or avatar stacks competing with the call to action | a single primary call to action, with one quieter secondary option at most | other actions live in navigation or further down the page |
| A feature grid where each card pairs an emoji icon and a bold heading with filler copy | a shorter feature list whose text names concrete capabilities | every card states the capability it describes |

## Hero composition and visual

Extends the SoT entries **Vibe-Coding layout** and **AI-generated 3D floating mesh / glowing geometric objects**.

| Trope | Decide instead | Passes when |
|---|---|---|
| Every hero element in one centered column, chosen without a reason | a composition derived from the hero visual's shape and the selected posture | one sentence ties the chosen alignment to the visual's shape and the posture; a centered column and a split both pass on a stated reason, neither by default |
| Decorative shapes or luminous lines filling the space behind the hero copy | an empty ground, or the single hero visual doing the work | nothing behind the text is decoration alone |
| A shiny rendered abstraction (3D shapes, metallic liquid, a space backdrop) standing in as the hero visual | a view of the actual product, or a single specific image of the job it does | one sentence states what the visual shows about this product |
| Stock machine-intelligence imagery — androids, lit-up brains, circuit traces, holograms | an example of the AI feature's output, or no image | the output shown is one the user supplied |

## Brand mark

| Trope | Decide instead | Passes when |
|---|---|---|
| A sparkle on a color-blended square, or lettering filled with a gradient | the name set in type, beside a simple single-color symbol | it reads in one solid color |
| A shiny sphere, color-blended ball or luminous dot as the symbol | a single-color glyph, or the name in type with no symbol | it stays legible at favicon size (**Scale minimums**) |

- An existing brand mark is not redrawn unasked: whether it counts as brand evidence, and how a matching trope is reported → `## Pre-Execution Verification` → **Visual Vocabulary Match**.

## Rows the SoT already carries

Pointers, not copies — the rule lives at the named entry.

- Gradient or shimmer on a headline → **Canvas/color tropes**
- Unsourced trust rows (customer counts, star ratings, avatar rows) → **Content tropes**
- Emoji as icons → **Font tropes**
- Decoration badges and sparkles outside the hero → **Default-style tropes**
