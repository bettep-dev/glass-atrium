Certificate

If this browser warned that the connection is not private, stop: do not enter the code. Trust the Mac's certificate first, once per device.

  1. On the Mac, send the certificate by AirDrop — its path is on the Mac's Remote access screen.
  2. iPhone or iPad: Settings → General → VPN & Device Management → install it, then Settings → General → About → Certificate Trust Settings → turn it on.
  3. Android: Settings → search “CA certificate” → install the received file.
  4. Before trusting it, compare its SHA-256 fingerprint with the one the Mac prints.
  5. Reopen this page.
